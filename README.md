# ذهن دوم — پلنر اندروید (آفلاین)

اپ پلنر فارسی و راست‌چین با Jetpack Compose. همهٔ اطلاعات فقط روی گوشی ذخیره می‌شود (بدون اینترنت و سرور).

## امکانات
- ورود / ثبت‌نام / خروج (رمز با PBKDF2 هش می‌شود) + تغییر رمز
- صفحهٔ اصلی: ساعت، ساخت سریع، آمار، نمودار عادت‌ها، درآمد و هزینه، کارها، پروژه‌ها
- بخش‌ها: کار، پروژه، نوت، هدف، عادت (با استریک)، ژورنال، درآمد، هزینه، غذا، وزن (نمودار)، کتاب، منبع
- تقویم شمسی، پومودورو و کرنومتر
- شخصی‌سازی کامل: رنگ، حالت تیره/روشن/آمولد، گردی گوشه‌ها، اندازهٔ متن، سبک کارت، چیدمان صفحهٔ اصلی
- پشتیبان‌گیری و بازیابی (فایل JSON)

## ساخت APK با گیت‌هاب (بدون نصب Android Studio)
1. در github.com یک Repository جدید بساز (مثلاً `SecondBrain`، حالت Private).
2. روی «uploading an existing file» بزن و **همهٔ محتویات** این پوشه را بکش و رها کن
   (شامل پوشه‌های `app` و `.github` و فایل‌های `build.gradle.kts`، `settings.gradle.kts`، `gradle.properties`).
3. Commit کن.
4. به تب **Actions** برو. workflow به اسم **Build APK** خودکار اجرا می‌شود (حدود ۵ تا ۸ دقیقه).
5. وقتی سبز شد، روی آن کلیک کن؛ پایین صفحه در بخش **Artifacts** فایل `SecondBrain-APK` را دانلود کن.
6. زیپ را باز کن و `app-debug.apk` را روی گوشی نصب کن (اجازهٔ نصب از منبع ناشناس را بده).

اگر Build قرمز شد، متن خطا را از تب Actions کپی کن و برای من بفرست تا درستش کنم.
